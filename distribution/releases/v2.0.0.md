# Hephaestus Workbench v2.0.0

v2.0.0 将客户端重构为轻量工程诊断宿主，固定一级入口为：

- 分析中心
- SSH 终端
- 扩展中心
- 设置

主要变化：

- 分析中心固定使用日志分析扩展，只选择“综合分析”或后续支持的“存储分析”。
- 报告统一由默认电脑浏览器打开，不再提供内嵌报告标签页。
- 扩展契约升级为 manifest/catalog schema v2，正式版只接受受信发布者签名包。
- Workspace 扩展只能从扩展中心进入固定受控 Host，不得贡献侧栏导航。
- 工作区和配置使用 `schemaVersion: 2`，不兼容旧数据，也不执行迁移、备份或删除。

正式 Release 只有在真实签名 Log Analyzer、锁定 Bundle 清单和宿主正式公钥信任锚全部就绪，并完成 Windows 10/11 x64 全新安装烟测后才能发布。
